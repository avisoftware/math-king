## About

Math King is a simple web-based math game where players solve math problems under time pressure. The game features a leaderboard, sound effects, and a clean, responsive UI.

## Features

- Random math problems
- Timer and scoring system
- Game over and leaderboard screens
- Sound effects for correct/incorrect answers
- Responsive design
